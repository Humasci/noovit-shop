# Hiring briefs (for the Upwork agent)

_From 14 Nov 2026 an agent posts jobs on Upwork for Noovit. Each brief in this folder is one role, ready to post._

## How it works
1. Claude writes a brief here whenever the project needs outside help, and flags it to the owner.
2. The owner OKs it; the agent posts the **Job post** section as written, adds the **Screening questions**, and uses
   **Must-haves** and **Red flags** to shortlist.
3. **The agent shortlists only.** The owner makes every hire, offer and payment decision. Never share logins, keys,
   customer data or the owner's personal details with applicants; files listed under "After hiring" go out only after a hire.
4. When someone is hired, update the brief's **Status** and the matching item in `docs/TODO.md`.

## Every brief has
A header table (status, priority, contract type, budget guide, screening questions, must-haves, red flags), the goal,
the scope, the **Job post** (copy-paste text) and what happens **after hiring**. Budgets are rough guides from market
rates; proposals set the real price.
